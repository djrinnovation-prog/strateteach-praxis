1ההחלטה בקצרה

  • StrateTeach מקבלת מערכת‑ניהול אחת במבנה SheraCore — אותו דפוס שמריץ את מרכז‑הניהול של Sheraton Grand TLV (sgtlv.com): תפקידים, פרויקטים, שרשראות‑אישור, קונסולה אחת.
  • מאמצים את הדפוס — לא את המימוש. הכול נבנה בתוך ה‑stack הקיים (React + FastAPI + Postgres). לא משכפלים את מבנה שני‑הקבצים / אחסון ה‑JSON של SheraCore.
  • קונסולת‑הבעלים היא ה‑shell. כל תחום‑עבודה הוא פרויקט בתוכה. StrateTeach‑Execution הוא פרויקט #1 — שירות‑הביצוע שכבר בבנייה (Phase 1, slice 1 merged).
  • אורן = מפעיל‑ביצוע מתוחם בתוך פרויקט #1, לפי גבול‑אורן המאושר (ראה §5).

4מה במפורש לא מאמצים

  • מבנה שני‑הקבצים / אחסון JSON של SheraCore — אצלנו הכול Postgres עם constraints (כמו שכבר נבנה ב‑slice 1), FastAPI ו‑React קיימים.
  • תפקידי‑רכש מלונאיים (supplier‑workflows, הזמנות‑רכש) — לא רלוונטיים; לוקחים רק את השלד.
  • אין שכפול משתמשים/הרשאות בשני מקומות — מודל‑התפקידים הקיים מיושר לשכבות, לא נבנה מערך מקביל.

5גבול‑אורן (מאושר — תזכורת)

  • אורן (execution_operator) רואה את כל המבנה הפיננסי: כספי‑חברה, מישור‑הביצוע (בוטים, סיגנלים, הזמנות, caps, reconciliation), דוחות מבניים.
  • חסום ממנו — owner‑only: הקרן המשותפת, השקעות‑הבעלים וכל תנועותיהן (הפקדות/משיכות/מסחר/NAV/אישורי‑3‑מ‑3).
  • ב‑DB זה כבר נאכף (slice 1: access.py + grants). בקוד‑האפליקציה עדיין הפוך (it_editor = full‑view‑minus‑finances) — יישור הגבול הוא חלק מעבודת P2 שמתוכננת כאן.

6תוכנית מימוש — P2 בפרוסות

פרוסהמהמגע בכסף?
2.1Schema: טבלאות projects + role_scopes (תפקיד ↔ פרויקט), יישור מודל‑התפקידים הקיים לשכבות 0–3לא. DDL בלבד.

כל פרוסה: build → deploy → אימות חי → אישור שלכם. הגייט החי נשאר כבוי לכל אורך הדרך; שום פרוסה כאן לא נוגעת בביצוע, במפתחות או בכסף.

7מה ממתין לאישור‑final שלכם

  1. אישור הדפוס — SheraCore כמבנה מערכת‑הניהול, בתוך ה‑stack הקיים (סעיפים 1–2).
  2. טבלת התפקידים (3.1) — השמות והשיוכים.
  3. רשימת הפרויקטים הראשונים (3.2) — Execution · קרן · משפטי · תוכן.
  4. סדר הפרוסות של P2 (סעיף 6) — או שינוי סדר לפי מה שדחוף לכם.
מסמך זה הוא טיוטה לאישור. אינו מבצע שום פעולה, אינו מזיז כסף, ואינו משנה הרשאות. הענקת תפקידים נשארת קליק של בעלים בפאנל.
